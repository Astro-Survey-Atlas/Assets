SHARED SCIENTIFIC CORE / DEVELOPER ENTRYPOINT

Build comparable sky coverage with MOC-Core-SDK

MOC-Core-SDK is the shared offline library for turning locked local inputs into deterministic ICRS/NESTED HEALPix coverage and IVOA FITS MOCs. It gives Assets, Workspace and Warehouse one spatial language for exchanging evidence.

WHAT THE CORE DOES

A deterministic scientific building block

The Core validates source geometry, canonicalizes cells, projects coverage to a requested order, and records provenance. It works offline after the input snapshot is locked, producing reproducible MOCs and package-ready outputs; hosted APIs and project databases stay outside its scope.

RELATIONSHIP TO ASSETS

Assets publishes the Core's verified outputs

Assets owns the public review and release workflow around MOC-Core-SDK. It locks source and evidence, invokes the Core, verifies the resulting MOC and provenance, then publishes the reviewed layer and Resource Package for downstream consumers. Workspace installs those public packages; Warehouse keeps its extraction compatible with shared fixtures.
