OFFLINE TOOLCHAIN / PYTHON + CLI

astro-survey-moc-core

A deterministic toolchain for reading coverage inputs, generating IVOA FITS MOCs, building query orders and Resource Packages, and validating every result.

INSTALL

Build a local wheel

python3 -m pip wheel --no-deps --no-build-isolation . -w wheelhouse
python3 -m pip install wheelhouse/*.whl

CLI

Check versions and build indexes

python3 -m astro_survey_moc_core.cli --version
astro-survey-moc-core project --moc merged.fits --order 8 --output query-order8.json

CONTRACT

Output contract

Use ICRS coordinates and NESTED HEALPix throughout. Order 4 is reserved for the home preview; order 8 or higher is published only when the input provides that precision. Missing precision is never inferred.
