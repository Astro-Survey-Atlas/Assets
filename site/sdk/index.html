OFFLINE TOOLCHAIN / PYTHON + CLI

astro-survey-moc-core

使用确定性的工具链读取覆盖输入、生成 IVOA FITS MOC、构建查询 order 和 Resource Package，并对结果执行严格校验。

INSTALL

构建本地 wheel

python3 -m pip wheel --no-deps --no-build-isolation . -w wheelhouse
python3 -m pip install wheelhouse/*.whl

CLI

检查版本与生成索引

python3 -m astro_survey_moc_core.cli --version
astro-survey-moc-core project --moc merged.fits --order 8 --output query-order8.json

CONTRACT

输出约束

统一使用 ICRS 坐标和 NESTED HEALPix。order-4 可用于首页预览，order-8 或更高 order 只在输入真实提供时发布，不对缺失精度进行推断。
