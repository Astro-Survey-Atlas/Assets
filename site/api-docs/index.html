COVERAGE / NATIVE UNITS / SOURCE MANIFESTS

Query the sky through the API.

Get a survey's published HEALPix list at an order, inspect service status, and use a Key for full native unit lookup and download plans.

Public coverage

No Key is required for the published survey catalog or HEALPix lists. Default selection is the union of all published survey MOCs. Use releaseId or productId to narrow it.

/api/v1/coverage/surveys/euclid/healpix?order=4

Full lookup with a Key

An administrator issues a Key with region:query and a quota of up to 30 requests per minute. It enables full reverse lookup and frozen manifest pagination. Accounts and online payment are not currently available.

Preserve the evidence

Results retain actual orders, native unit identities, precision and inventory limits. JSON/CSV plans contain metadata and links; users retrieve scientific data from each source.
