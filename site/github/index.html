PROJECT RESPONSIBILITIES

Choose the repository that owns your work

Assets

Use Assets to add or review a public survey, publish a MOC or Resource Package, improve public overlap and reverse lookup, or work on the public website.

Warehouse

Use Warehouse for source enumeration, spatial extraction, ScanPlan execution, the Kubernetes operator, current-state indices and scan evidence production.

Workspace

Use Workspace for private or local assets, connectors, workflows, user task history, user MOCs and exploration that combines user data with verified public packages.

PUBLIC DATA PROMISE

Every public result states its source and precision

ICRS/NESTED order, exact or estimated precision, source snapshots, output hashes and official archive links stay attached to the published result. Preview cells are never promoted into finer coverage.

INDEPENDENT DATA PLANES

Contracts connect the projects; databases do not

Assets owns public publication, Warehouse owns execution and current scan state, and Workspace owns user data. Credentials, task history and user records remain in their owning project.

CONTRIBUTE

Public coverage changes begin in Assets

Include the survey and release identity, source snapshot, coordinate frame, real HEALPix orders, precision, output hashes and reproducible verification steps. Scanner or operator changes belong in Warehouse; user workflow changes belong in Workspace.
