PROJECT INTRODUCTION

One atlas, separate data planes.

Astro Survey Atlas is the public front door for survey coverage. Assets publishes reviewed layers, Warehouse executes bounded scans, Workspace keeps user data private, and the shared scientific core keeps their spatial contracts compatible.
