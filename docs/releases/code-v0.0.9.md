# Assets 0.0.9（code）

日期：2026-11-09。此代码版本不发布 public bundle、不激活原生索引，也不下载科学数据。
部署与实际验收状态见 [HANDOFF](../../HANDOFF.md)。

## 变更

- Coverage layer 悬浮卡离开后延迟 2 秒关闭，进入卡片/触发行或保持键盘焦点可继续阅读；
  卡片支持滚动，快速切换不被旧计时器关闭，阅读期间暂停图层列表自动收起。
- 卡片 DR 与产品名称分列对齐，真实最高原生阶数/可用阶数独立显示；勾选产品同步更新。
- 清理重复历史交接、过期实施计划和无引用图片；新增文档索引，保留来源研究、审计收据与设计基线。
- 修正文档中过时的 O4 源覆盖策略、管理台导航、区域反查限制、可选 collection 及私有数据恢复边界。
- package、lockfile 根包、Chart、默认镜像 tag 和 health 版本统一为 0.0.9。

## 验收范围

悬浮卡专项浏览器回归覆盖 1999/2000ms 边界、重入、跨行、键盘焦点、列表自动收起
暂停/恢复、隐藏清理和长名称布局。代码发布验证不证明所有大区域反查或巡天库存完整；
真实大重合区域解锁/完整续页的用户场景仍须单独验收。

生产升级继续使用原有经审核数据和恢复配置；本地文档 manifest 的更新不切换线上数据版本。
