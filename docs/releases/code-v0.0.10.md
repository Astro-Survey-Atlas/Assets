# Assets 0.0.10（code）

日期：2026-11-09。此代码版本不发布 public bundle、不激活原生索引，也不下载科学数据。
部署与实际验收状态见 [HANDOFF](../../HANDOFF.md)。

## 变更

- 修复 Target Lock 真正的外层滚动容器：同内容缓存刷新保留 DOM，必要重建离线构造后一次替换并同步保持滚动位置；缓存证据不先换成骨架屏。
- 面板标题及留白接收指针事件，避免滚动穿透至天球；中断的证据查询可恢复。
- 重合详情抽屉打开时，以完整连通区域为拾取单位，点击区域本体/标签与抽屉同步，不再触发隐藏的单 HEALPix 详情或 depth 查询。
- 区域提示展示实际 component/order/cell 数、ICRS/NESTED 面积以及区域来源的巡天、DR 和模态；缺失信息不以整个巡天的声明冒充区域证据。
- 关闭抽屉恢复单元查看。共享组件固定为独立仓库 `sky-globe` 的 `v0.1.2`，默认交互兼容原使用方。

## 验证边界

- 首页/Atlas Chromium 回归覆盖真实外层滚动逐帧采样、O6 零请求缓存刷新、同目标重选、非空证据缓存、抽屉中断恢复，以及真实鼠标区域 hover/click、抽屉切换、空白天空不选择、关闭后恢复单元查看。
- 本地真实公开数据预览已操作 Euclid × DESI 的 C04 / O6 / 47 cells，区域提示与抽屉一致，page errors 为零；不作为生产验收。
- sky-globe 类型检查及 27 项单测通过，Assets 类型及浏览器回归通过。
- 不证明认证大区域的完整续页/导出或所有巡天库存完整。生产部署结果单独记录。
