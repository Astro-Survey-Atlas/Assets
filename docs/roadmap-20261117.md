## Context

- **两种运行模式**：
  - **SaaS 模式（无 Warehouse）= 只读运营服务**：展示天球和 MOC 覆盖、点击反查返回结果、接受 API 调用、发授权码/API Key。**不能新增或修改任何数据**：没有探查、扫描、构建、导入、审核、发布、native 索引激活。数据只来自从 S3 同步已发布的 release。

- 说明：SaaS 实例获得 native 索引的途径是 S3 同步（`#adoptPointer`），不使用导入接口；导出/导入只在数据生产实例上用于备份、迁移和跨实例复制。
- 现状：激活写 `native-units/versions/<groupId>/<sha>.json` 与 `current.json`（CAS，`controller.ts:241-249`）；`#adoptPointer`（:258-273）校验 manifest SHA 与 `nativeGroupId` 并 `restoreNativeFile` 双哈希校验。缺：导出/导入非当前版本、离线 bundle 格式、整组导入。
- bundle：tar，含 `bundle.json`（`schemaVersion`、`kind:"native-index-export"`、`groupId`、`manifestSha256`、文件清单）、与激活时字节相同的 `group.json`、`files/<sha>[.gz]`。
