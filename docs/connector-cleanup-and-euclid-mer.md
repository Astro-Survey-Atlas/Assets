# Connector 清理与 Euclid Q1 MER 数据用途

2026-09-21。核心目标是从实际数据建立覆盖，再按重合区域反查文件，减少无关下载。

## 删除连接

后台“数据来源”选中连接后，在详情操作区点击“删除连接”，确认后执行。
只删除 Assets 管理的连接 ConfigMap 及探测/盘点缓存；不删除桶、对象、PVC、扫描历史、
覆盖索引或已发布产品。任务状态读取失败或关联扫描未结束时拒绝删除。
Warehouse 原生 AstroDataSource 需在其来源系统管理，本页按钮禁用。

保留 Secret，因为历史冻结 ScanPlan 或其他连接可能引用它；删除连接不等于撤销
存储凭证。新建同名连接使用新 Secret，不覆盖历史凭证。新扫描/通过 Assets 重试前
需要重新建立连接。界面不自动挑选或批量删除任何过时连接。

## 围绕覆盖和反查的接入顺序

1. 先限定一个 Tile 的 VIS 科学影像验证；按仪器、波段和产品类型筛选，排除背景/PSF。
2. 以 FITS WCS 生成文件边界，保留 Tile ID、源对象身份、大小、坐标系和可用下载入口。
   边界和有效像素掩膜不同；有空白/坏像素时应披露限制，不能宣称每个像素有效。
3. 建立空间像元到原文件的覆盖索引，验证真实重合区域只返回相交 Tile 文件。
4. 扩展到 VIS 与 NISP H/J/Y；RMS/FLAG 按需关联到对应科学影像。
5. 构建可审核的 MOC/索引并按原有门禁发布，明确镜像已扫描范围与完整公开 MOC 的区别。

第一阶段减少的是下载文件数量；不会自动裁切 FITS 或只下载星表命中行。
更细的 cutout/行筛选需要独立服务。私有存储位置不可直接冒充匿名公开下载地址，
应使用可验证的官方入口或授权下载服务。

当前 Warehouse CatalogHandler 读取 CSV/TSV/文本星表；现有 catalog-radec 不能直接
处理 FITS BINTABLE。若后续确有源星表，应先确认格式与坐标列，再选择兼容输入或补适配。
不能把 PSF 影像或表头中心点当作源星表分布。
