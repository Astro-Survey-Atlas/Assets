## 真实输入及展示含义

输入来自只读 `desi-dr1-local` 的 iron v1 `zall-pix-iron.fits`。适配器已将
32,768 个连续源行 `[4700000,4732768)` 保存为 evidence，数据未进入 Git 或发布包。
本轮复用该固定 SHA-256 的样本，不重新扫描 22 GB 总表，也不将这个窗口视为完整天区。
来源访问任务、FITS 头/行字节哈希、质量条件和整文件哈希未重新验证的限制，见
[可行性报告](research/healpix-distance-feasibility-20261030.md)。

开发链接从该输入中选择有效距离对象最多的 O4 cell **630**：

| 当前输入中的对象 | 数量 |
| --- | ---: |
| 坐标位于该 cell 的源行 | 6,612 |
| 符合红移展示条件的主测量星系 | 4,222 |
| 适用当前距离展示策略的星系 | 4,198 |
| 距离模式实际绘制的聚合光点 | 2,296 |

只展示 aggregated points。每个光点是一个角向 HEALPix 子格与径向区间的聚合，
位置采用子格中心和该箱内测量值的加权平均，点击显示来源、对象数、真实聚合阶数/像元和箱边缘。
选中 HEALPix 始终保留白色底面轮廓；有适用测量的区块才沿选区法线升起框线，高度对应该区块的
最大测量值。其他区块保持空心，底面面积和区块数不会随高度增加。所有区块与 HEALPix 阶数
共用该数据来源的固定径向刻度，切换选区不会重新拉伸高度；刻度是视觉长度，不代表等比例宇宙体积。

**屏幕圆点面积与对象数成正比，直径与数量的平方根成正比**；4 倍对象数对应 2 倍直径。
镜头远近不改变此数量标度。使用统一缩放限制最大点径，保持所有点之间的面积比例；
DEPTH 使用相同比例的数量图例，当前样本显示 1、4、11。颜色从暖到冷表达当前纵深轴的低到高值。
背景覆盖弱化，光点会被天球前表面遮挡；背面光点不可穿透天球点选。

双端范围滑条在 Mpc 或 z 的完整来源刻度上强调一个区间：区间内聚合点保持原色，区间外聚合点保留原色并以 50% alpha 与天球背景混合，不额外染灰，也不阻断后方聚合点。按每个聚合点的径向加权均值判断范围；不改变聚合数量、径向数据或服务器查询。HEALPix 线框内增加两道与选区同形的平行截面框，标记滑条上下界；它们沿固定径向刻度定位，不填充也不连接侧边。
Mpc 与 z 分别保存上次使用的范围；可用键盘调整滑块端点。

“距离”明确是 **Astropy Planck18 的视线共动距离、红移空间估计**。保留 barycentric
参考系，未校正本动速度或 CMB 参考系。误差只传播光谱红移测量项，系统误差未知。
距离模式采用保守展示范围 `0.02 ≤ z ≤ 2`，不是宣称范围内所有对象的距离都可靠。
红移模式独立筛选，保留其他有效测量 z；此时纵轴和颜色标为低/高 z，不冒充 Mpc 或真实远近。
Mpc 是兆秒差距，1 Mpc 约 326 万光年；它是通用长度单位，Planck18 是由红移推算共动距离所用的模型。
模型、筛选条件、窗口和样本哈希都能在界面中查看。

当前天球入口始终请求完整聚合，不截断对象；不再提供逐天体散点或细柱模式。角向策略：

| 选区阶数 S | 优先角向聚合阶数 A |
| --- | --- |
| O4 | O8 |
| O6 | O10 |
| O8 | O12 |
| O10–O13 | O13 |

A 来自实际天体坐标，最高 O13；如果非空体元超过 32,768，再尝试
`min(S+2,13)` 和 S。径向 64 箱在固定来源全局范围内计算，返回真实箱边缘、计数和箱内加权平均值。
每个选中 cell 另返回适用测量的最大值和数量；一个 cell 内无适用测量时不产生高度。
聚合光点表示该箱内测量值的加权平均位置，点击显示该统计单元的对象数。O4 #630
实际为 A=O8、64 个径向箱；2,296 个聚合点仍表示全部 4,198 个合格对象。
高阶 cell 没有足够真实对象时不补点，过宽的选区隐藏可选纵深。

## 可选能力边界

当前唯一接通的测量来源是 DESI DR1 行窗口；`desi-dr1`/`dr1` 是显式发布身份映射，
不混用 EDR。查询按坐标和角选区筛选该目录输入，并非被点击产品的逐文件目标清单，
不把光谱产品覆盖当作测量完整性证明。选择其他巡天时，可以将 DESI DR1 标为**坐标参考纵深**，
展示同一 ICRS 天区中的 DESI 对象；这不表示这些对象属于所选巡天，也不执行对象级交叉匹配。
其他巡天仍各自报告“尚未接入”，不推断它们没有红移。尚未实现多个实测巡天的融合。

逐来源区分 `available`、`redshift-only`、`no-measurements`、`not-connected`、
`empty`、`unavailable`。仅有红移时可切到 z；空结果限定在输入范围内；错误不能变成
零对象。全无可用数据时隐藏面板；部分来源有数据时，可在“来源与距离依据”查看各自状态。
参考来源在 DEPTH 中直接标为 `DESI DR1 · reference depth`，并说明没有跨巡天天体匹配。
25 秒前端超时，清除和切换会取消失效请求；失败或空结果后重新选择可再次读取。二维覆盖、
重合和来源信息独立可用，不使用合成数据填补失败结果。

## 服务配置与接口

正式 backend 接口为 `GET /api/v1/sky-depth/example` 和 `POST /api/v1/sky-depth`，
已列入 OpenAPI。未配置输入时，示例报告不可用，来源报告未接入；读取错误按来源返回。
正式启用须显式设置：

- `ASSETS_EVIDENCE_ROOT`：已有 evidence 根目录。
- `ASSETS_SKY_DEPTH_SAMPLE_PATH`：该根目录内的固定样本路径，解析真实路径并检查边界。
- `ASSETS_SKY_DEPTH_SAMPLE_SHA256`：预先确认的样本哈希，读取时验证；输入上限 32 MiB。

ICRS/NESTED，S=4–13，最多 4,096 cells、16 个来源，JSON 请求不超过 64 KiB。
来源可带 `role: "reference"`，当前只允许 DESI DR1。接口返回实际表示方式、聚合阶数、
稳定来源径向范围、每个所选 cell 的最大测量值与数量、每个聚合箱的加权径向均值和计数、
输入窗口与哈希、距离依据。
响应 `no-store`，原始行不会进入初始页面请求或 MOC/公开包。Planck18 参考表已包含在
运行镜像中；本轮没有更改 Warehouse 契约、安装索引、发布 MOC 或启用生产物理量索引。
