# Distance model fixture

`planck18-reference.json` contains a deterministic numerical model table, not observed survey data.
It is generated by `python3 scripts/generate-distance-reference.py` with numpy, astropy and scipy.
The file records the library version, full Planck18 parameters, units and valid redshift domain.
Browser interpolation is linear and refuses extrapolation. Its numerical error is distinct from
redshift measurement error and the unknown physical/systematic distance error.

The prototype defaults to synthetic objects in memory and can import a bounded local DESI
evidence sample through its file input. Real source rows, scan snapshots, and normalized science
catalogues belong in the configured evidence store, never in this directory or the initial page load.
